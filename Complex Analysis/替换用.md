# 在LaTeX中将数学环境替换为包含\displaystyle的版本
你可以使用正则表达式来批量替换LaTeX文档中的数学环境，添加`\displaystyle`。以下是几种常见数学环境的替换方法：

## 单行数学环境

1. 替换 `$...$` 为 `$\displaystyle ...$`:
   ```
   查找: \$(.*?)\$
   替换: $\displaystyle $1$

   查找: \$\$(.*?)\$\$
   替换: $$\displaystyle $1$$
   ```

2. 替换 `\(...\)` 为 `\(\displaystyle ...\)`:
   ```
   查找: \\\((.*?)\\\)
   替换: \(\displaystyle $1\)
   ```



## 多行数学环境

1. 替换 `\[...\]` 为 `\[\displaystyle ...\]`:
   ```
   查找: \\\[(.*?)\\\]
   替换: \[\displaystyle $1\]
   ```

2. 替换 `begin{equation}...\end{equation}`:
   ```
   查找: \\begin\{equation\}(.*?)\\end\{equation\}
   替换: \begin{equation}\displaystyle $1\end{equation}
   ```

3. 替换 `begin{align}...\end{align}`:
   ```
   查找: \\begin\{align\}(.*?)\\end\{align\}
   替换: \begin{align}\displaystyle $1\end{align}
   ```
